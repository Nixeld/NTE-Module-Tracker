# NTE Module Tracker

A web application to help track modules for characters in **Neverness to Everness (NTE)**. This tool assists players in determining which modules they need to select when rewinding for modules.

<img width="1437" height="1253" alt="2026-06-28_22-43" src="https://github.com/user-attachments/assets/dbae9bcc-af32-4f47-b51b-ef4d7174f823" />

## Features

- Track multiple characters and their required modules
- Persistent storage using localStorage
- Module summary showing total counts across all characters
- Responsive design

## How to Use

- Access the tool using this link: https://nixeld.github.io/NTE-Module-Tracker/
